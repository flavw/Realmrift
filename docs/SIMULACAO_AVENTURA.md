# Simulação automática de aventura



Duelos resolvidos pelo motor real, sem atribuir vitórias. Um agente heurístico joga pelo protagonista; o adversário usa a IA normal. Sem interface ou animações. Este resultado não demonstra equilíbrio de todas as campanhas.



Nota de auditoria: uma execução preliminar foi descartada porque revelou uma configuração incorreta de collectible no Campeão da Fenda. A propriedade foi movida para depois do vínculo do script no recurso; as cartas exclusivas foram verificadas como não colecionáveis. As seis tentativas abaixo foram realizadas após essa correção. Não houve alteração de balanceamento para obter vitórias.
